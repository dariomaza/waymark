# Words

- `en.ts` is the SOURCE: `Dictionary` is a type derived from it, so a key
  missing from `es.ts` does not compile. Add every key to both, with a doc
  comment saying what the sentence is FOR.
- **Spanish is tú, never usted.** The header of `es.ts` explains why the rule is
  written there rather than remembered. A possessive `su` is still right when it
  belongs to a thing.
- A parity test compares the placeholder set of every phrase in both languages.
- **`refusals.ts` turns a failure into a sentence, and the sentence must name the
  layer that failed.** A device failure (WebAuthn, an unreadable photo) is never
  described as the server's, and an unrecognised throwable is `failure.unexpected`,
  not `failure.server`. A browser's own token (a `DOMException` name) is passed
  through untranslated inside the translated sentence.
- **Test the key, not the rendering.** Two sentences that interpolate a
  different value always render differently, so a "each case has its own
  sentence" test must compare `Message.key`.
- Spanish copy has had no native reviewer yet; flag anything you are unsure of.
